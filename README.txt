HƯỚNG DẪN NHANH

1. Mở file index.html để xem website.
2. Thay ảnh trong thư mục assets nếu muốn đổi ảnh cưới.
3. Các nội dung text chính nằm trong file index.html.
4. Hiệu ứng tim bay, modal, countdown, lịch tháng và form RSVP nằm trong script.js.
5. Giao diện nằm trong styles.css.

NHỮNG CHỖ NÊN SỬA SAU
- Tên khách mời ở phần hero: "Quý khách thân thương"
- Link Google Maps chính xác cho nhà trai / nhà gái
- Thông tin ngân hàng và số tài khoản trong modal mừng cưới
- Nếu muốn phát nhạc thật, thêm file audio rồi gắn logic phát nhạc trong script.js

LƯU Ý
- Bộ code này là bản remake premium từ giao diện công khai của trang gốc, không cần source code cũ.
- Một số thông tin như QR ngân hàng chi tiết không đọc được đầy đủ từ ảnh chụp nên đang để placeholder.
